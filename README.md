# A Two-Phase Multi-Split Causal Ensemble Model for Time Series

This repository contains the research and implementation related to "A Data-Driven Two-Phase Multi-Split Causal Ensemble Model for Time Series" (arXiv:2403.04793).

The primary goal is to develop robust methods for causal discovery in time series data.

## Core Components:

*   **`chronus_causus/`**:
    *   The main Python library, `chronus_causus`, which implements the causal ensemble model. This is the focus of ongoing development for a reusable and extensible tool.
    *   See `chronus_causus/README.md` (to be created) and `chronus_causus/roadmap.md` for more details on the library itself.

*   **`demostration/`**:
    *   Contains the original Python scripts and utilities used for the research and experiments presented in the paper. This serves as a proof-of-concept and reference implementation.

*   **`example_fakedata/`**:
    *   Includes Jupyter notebooks demonstrating the usage of the model with synthetic datasets.
