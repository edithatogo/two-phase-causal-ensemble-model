# chronus_causus

A Python library for timeseries causal discovery using an ensemble model, based on the paper "A Data-Driven Two-Phase Multi-Split Causal Ensemble Model for Time Series."

This library is currently under development. Please refer to `roadmap.md` for the development plan.
